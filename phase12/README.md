# EdgePilot Phase 12: Hosted Qualcomm Validation

This directory contains the hosted validation results for the true end-to-end (E2E) model generated by EdgePilot during Phase 11.

Phase 11 proved the ability of the EdgePilot pipeline to automatically build, train, validate, and export a task-specific YOLOv8-N model starting from a raw custom dataset. Phase 12 takes that *exact* generated artifact and submits it to the Qualcomm AI Hub for profiling.

## Workflow Summary

1. **AutoML Pipeline**: Phase 11 produced a task-specific ONNX model trained locally on the Mac using the NEU-DET custom dataset.
2. **Initial Submission**: Phase 12 submitted this specific artifact (`runs/detect/runs/custom_219d4d96/weights/best.onnx`) directly to the Qualcomm AI Hub API.
3. **Graph Sanitization**: Qualcomm initially rejected the raw ONNX because of an ONNX IR/value_info metadata conflict (`Tensors {'output0'} occur in value_info but also in model IO`). A graph-level ONNX sanitization was applied without retraining or changing the architecture. The sanitized artifact (`phase12/custom_model/best_sanitized.onnx`) was structurally validated.
4. **Compilation**: The sanitized deployment artifact was compiled specifically for the **Snapdragon X Elite CRD**.
5. **Profiling**: The compiled model was profiled using the ONNX runtime with FP16 precision, strictly utilizing the device's **NPU (Neural Processing Unit) / HTP**.

## Results
The validation benchmark results returned from Qualcomm AI Hub are recorded in `qualcomm_benchmark.json`. Key metrics such as Compile Status, Profile Status, Inference Latency, Peak Memory, and the specific Job IDs were recorded.

**Note on Scope of Validation:**
- This is a *hosted* Qualcomm hardware validation performed over the cloud via Qualcomm AI Hub.
- A physical local Snapdragon Windows laptop validation has not yet been performed.
- EdgePilot is a reusable edge-AI workflow for deploying task-specific models, not a single universal AI model.
- The sanitization step is a deployment-format compatibility fix for the ONNX parser, not an accuracy improvement.
